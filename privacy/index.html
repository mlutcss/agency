2. Какие персональные данные обрабатываются

  • Имя — имя, указанное пользователем.
  • Контакт для связи — адрес электронной почты, идентификатор или ссылка на аккаунт в Telegram, WhatsApp либо иной контакт, указанный пользователем.
  • Запрос — описание проекта, задачи или вопроса, если пользователь заполнил соответствующее необязательное поле.

2.2. Поля «Имя» и «Контакт для связи» необходимы для рассмотрения заявки и направления ответа пользователю. Поле «Запрос» является необязательным.

2.4. Оператор не запрашивает через форму паспортные данные, сведения о здоровье, биометрические персональные данные и иные сведения, не необходимые для рассмотрения заявки.

Пользователям не следует указывать такую информацию в поле «Запрос».

3.2. Оператор использует персональные данные исключительно для целей, связанных с обращением пользователя и возможным сотрудничеством.

3.4. Оператор не продаёт персональные данные и не распространяет их среди неопределённого круга лиц.
